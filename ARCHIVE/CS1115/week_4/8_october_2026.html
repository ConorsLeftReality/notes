Heirarchal Structure

File systems are like trees (If you were viewing one upside down)

HTML is also like trees in their elements

  • Trees are graphs made of nodes
  • Nodes have one parent (or none)
  • A node can also have ancestors (Parent(s) of their parent)
  • A Node's descendants are the nodes that connect back to a given node
  • A node's siblings are nodes who share the same parent
  • The eldest node is the first occuring node from a parent

But why is this important?

Because fuck you, that's why.

(The browser builds a webpage in order of the tree, from eldest to youngest)

Syntax of HTML

  • Only certain tags are permitted
  • Only certain attributes and values are permitted. E.G.
    • Any element can have the lang attribute as its Global
    • Only a few elements can have alt attributes
  • Often, only certain content is permitted
    • <p> cannot contain <p>
    • <p> cannot contain <ul> or <ol> elements
    • <ul> or <ol> can only contain zero, one or more <li> element
  • Nesting must be done correctly

Types of HTML syntax

HTML has 2 types of syntax, XML and HTML formatting

  • XML syntax uses very strict rules
  • HTML syntax allows for rules to be broken

In XML...

  • Tags must be lowercase
  • Each start tag needs an end tag, or a slash for void elements
  • Attribute values must be quoted
  • and more...

Browsers dont give error messages, but you can validate your page on https://validator.w3.org/nu/ or https://validator.w3.org/

Subqueries

A subquery is a query inside another query. The outer query uses its result as a value, a list of values, or a temporary table

They can go in the WHERE clause, the FROM clause, or the SELECT list

scalar_subquery.sql
-- The film(s) with the highest score
SELECT title
FROM movies
WHERE score = (SELECT MAX(score) FROM movies);

IN and EXISTS

  • x IN (subquery) - true if x is one of the results
  • EXISTS (subquery) - true if the subquery returns any rows
  • Both have NOT versions: NOT IN, NOT EXISTS

Subquery in FROM

Acts like a temporary table, give it an alias so you can use it

from_subquery.sql
-- Students with more points than average
SELECT first_name, last_name
FROM students, (SELECT AVG(points) AS avg_points FROM students) AS avg_table
WHERE points > avg_table.avg_points;

Compound Select

Another way to solve a problem: split it into smaller queries, solve each one, then combine the results

  • UNION - rows from either query, duplicates removed (UNION ALL keeps them)
  • INTERSECT - rows in both queries
  • EXCEPT - rows in the first query but not the second
intersect.sql
-- Films with both Humphrey Bogart and Katharine Hepburn
SELECT movieid FROM castings
JOIN actors ON actors.id = castings.actorid
WHERE name = 'Humphrey Bogart'
INTERSECT
SELECT movieid FROM castings
JOIN actors ON actors.id = castings.actorid
WHERE name = 'Katharine Hepburn';
NOTE

Every SELECT has to return the same number of columns. The column names come from the first one, and only the last one can have ORDER BY / LIMIT. SQLite doesn't allow brackets around the parts

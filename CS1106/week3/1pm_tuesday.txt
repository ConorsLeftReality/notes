## Relational Operations

projections, selections and joins
SQL uses the SELECT command to run these operations

    Projection operations retrieve specific columns (attributes)
    Selection operations retrieve specific rows (tuples)
    Join operations bring together the data from two or more tables

## SQL Queries (DQL)

The query specifies what data is required (what data is required and where its from).
The result of query is a table.

# SQL DQL Template 

    SELECT list-of-attributes
    FROM table-name;

    list-of-attributes is a comma seperated list of column names

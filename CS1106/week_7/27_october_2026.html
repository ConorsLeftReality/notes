Joining More Than Two Tables

Joins usually link a primary key in one table to a foreign key in another. A multi-way join just keeps going: joining n tables is done as (n - 1) two-way joins, and the order doesn't matter (joins are associative)

multiway_join.sql
SELECT actors.name, movies.title
FROM actors
JOIN castings ON actors.id = castings.actorid
JOIN movies   ON castings.movieid = movies.id
WHERE movies.yr = 1972;

Building a Complex Query

Don't write it all in one go, build it up step by step

  1. Understand the question - what should the output look like?
  2. Find the tables you need and how they're linked (primary/foreign keys)
  3. Join them
  4. Check the join - right rows? duplicates? anything missing?
  5. Pick the columns (projection)
  6. Filter the rows (WHERE)
  7. Group if it says count / total / average / max / "per something" (GROUP BY)
  8. Conditions on the groups (HAVING)
  9. Sort and limit (ORDER BY, LIMIT)
NOTE

SQL runs the clauses in this order, not the order you write them: FROM/JOIN, WHERE, GROUP BY, HAVING, SELECT, ORDER BY, LIMIT

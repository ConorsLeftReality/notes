Intro - Data and Arithmetic Operations

Data Analysis

Finding trends in data often requires processing the data before creating the result.

Data is usually stored at the lowest level of granularity possible.

NOTE: Null is used when it is nessecary to record the absence of a value.

Attributes(?)

Each column in a database table will have a datatype/attibute.

E.G.

  • Name - TEXT
  • Region - TEXT
  • Area - in km**2 INT
  • Population - INT

Arithmetic Operations

Perform mathematical operations on table column(s) in a query

More completely, these can be performed on

  • A single column
  • Two or more columns
  • Constant values with column data
Operator Desctiption
+ Addition
- Subtraction
/ Division
* Multiplication
% Modulus (remainder)

Example of possible use (Population Density)

example_arithmetic_operation.sql
SELECT name, population/area
FROM countries
WHERE region = 'Europe'
ORDER BY population/area DESC;

Aggregation

Summarise the data from all or part of a table

Aggregation Function

A function that performs a calculation on a set of values and returns a single value

SQL Aggregation Functions

COUNT() is the number of values of an attribute

E.G. Counts the number of rows in a specified field

SELECT COUNT(name) FROM countries; returns the number of values in the name column of table countries

SELECT COUNT(gdp) FROM countries; return the number of values in the gdp column of table countries

Query 1 could return a higher value than Query 2, as some of the fields in the gdp column could be NULL

Other Aggregation Functions

  • MIN () - Smallest Value in column
  • MAX () - Highest Value in column
  • SUM () - Sum of a numerical column
  • AVG () - Average value of a numerical column
Note

If the list of attributes in SELECT is a single aggregation function, the result is a 1 x 1 table

Unique Values

DISTINCT ensures each value in a column is only counted once, which can be used with any aggregate function but makes most sense with COUNT ()

E.G. SELECT COUNT(DISTINCT region) FROM countries; would return the number of unique regions in a table

Grouping

Aggregate functions are applied to groups of rows

If no group is specified, there is a single, implicit group consisting of all the rows in the table

By defining a group, aggregate functions can calculate totals, counts, the average, smallest, and largest values within each group

How do we group?

Add the clause GROUP BY to the SELECT statement

E.G. 
SELECT region, SUM(population) 
FROM countries
GROUP BY region;

This returns the sum of the population for each region, based off of common regions for each country

Dictionaries

Note

No notes were taken in this lecture, so this page was written up from the slides afterwards. Most of the code on the slides is in images, so the examples here are written to match them.

A dictionary stores key: value pairs (also called a hash table or associative array). You look things up by key instead of by position.

dictionaries.py
d = {"duck": "water", "horse": "land"}

d["duck"]          # "water"
d["back"]          # KeyError - the key doesn't exist
d.get("back", "?") # "?" - get() gives a default instead of crashing

del d["horse"]     # d is now {"duck": "water"}
d["back"] = "rug"  # insert a new key
d["duck"] = "duik" # overwrite an existing key

Going through a dictionary

traversing.py
d = {"duck": "water", "horse": "land", "back": "rug"}

d.keys()    # the keys:   "duck", "horse", "back"
d.values()  # the values: "water", "land", "rug"
d.items()   # the pairs:  ("duck", "water"), ("horse", "land"), ("back", "rug")

for animal, place in d.items():
    print(animal, "lives on", place)

if "duck" in d:   # 'in' checks the keys
    print("found")

keys(), values() and items() give a view of the dictionary rather than a copy. Use a for loop to process them (or list() to turn one into a list).

Example: letter frequency

letter_frequency.py
text = "wuthering heights"
freq = {}
for letter in text:
    if letter.isalpha():
        freq[letter] = freq.get(letter, 0) + 1   # add 1 to its count

total = sum(freq.values())
for letter, count in sorted(freq.items()):
    print(letter, round(count / total * 100, 1), "%")

The slides also use a dictionary to translate Wuthering Heights into Morse code: the keys are letters and the values are their Morse codes, e.g. {"a": ".-", "b": "-...", ...}.

List Comprehensions

A list comprehension builds a new list from another in one line. It's square brackets around an expression, a for clause, then optionally for/if clauses. It always gives you back a list.

syntax.py
new_list = [expression for item in old_list if condition]

# is the same as:
new_list = []
for item in old_list:
    if condition:          # the 'if' part is called a filter, and is optional
        new_list.append(expression)
squares.py
# Squares of 1 to 10, the long way
squares = []
for x in range(1, 11):
    squares.append(x ** 2)

# The same with a list comprehension
squares = [x ** 2 for x in range(1, 11)]

# Only the odd squares (with a filter)
odd_squares = [x ** 2 for x in range(1, 11) if x % 2 == 1]   # [1, 9, 25, 49, 81]

# Nested loops
pairs = [(x, y) for x in range(3) for y in range(3)]

When to use one: when it's short and still easy to read. If it gets long or complicated, a normal loop is clearer.

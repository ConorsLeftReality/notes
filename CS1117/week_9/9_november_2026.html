2D Matrices (Lists of Lists)

Note

No notes were taken in this lecture, and the slides couldn't be opened when this page was written, so it covers the standard material on 2D lists. Check it against the slides.

A 2D matrix in Python is a list of lists: each inner list is one row.

matrix.py
matrix = [[1, 2, 3],
          [4, 5, 6],
          [7, 8, 9]]

matrix[0]       # [1, 2, 3]  - the first row
matrix[1][2]    # 6          - row 1, column 2 (both start at 0)
len(matrix)     # 3 rows
len(matrix[0])  # 3 columns

Going through every element (nested loops)

nested_loops.py
for row in range(len(matrix)):
    for col in range(len(matrix[row])):
        print(matrix[row][col], end=" ")
    print()   # new line after each row

# Row totals
for row in matrix:
    print(sum(row))

Making an empty matrix

make_matrix.py
rows, cols = 3, 4
grid = [[0] * cols for _ in range(rows)]   # 3 separate rows of 4 zeros
Watch out

[[0] * 4] * 3 looks the same, but it makes 3 references to the same row, so changing grid[0][0] changes the first element of every row. Use the list comprehension above instead.

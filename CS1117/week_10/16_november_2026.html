Tuples

A tuple is a fixed group of related values. Like a list, but immutable - you can't change it once it's made

tuples.py
person = ("Ava", 19, "Dublin")
colours = "red", "green", "blue"   # still a tuple - it's the commas that count
one_item = (42,)                   # (42) on its own is just an int!

days = ("Mon", "Tue", "Wed", "Thu")
days[0]      # "Mon"
days[-1]     # "Thu"
days[1:3]    # ("Tue", "Wed")

name, age, town = person           # unpacking

No append(), remove() or sort(). To "change" one, make a new tuple: scores += (85,)

Sets

A set is an unordered collection with no duplicates

sets.py
a = {1, 2, 3}
b = {3, 4}
a.add(5)
a | b    # union        {1, 2, 3, 4, 5}
a & b    # intersection {3}
a - b    # difference   {1, 2, 5}
set([1, 1, 2])   # {1, 2} - quick way to remove duplicates

Match

Another way to branch, instead of a long if/elif chain

match.py
match command:
    case "start":
        print("Starting")
    case "stop":
        print("Stopping")
    case _:              # anything else
        print("Unknown command")

Files and File Types

Note

No notes were taken in this lecture, so this page was written up from the slides afterwards. Most of the code on the slides is in images, so the examples here are written to match them.

Computers use files to store documents, programs, images, webpages and more. Files are persistent: the data is kept between runs of a program, unlike normal program variables, which disappear when it ends.

  • Text files - only printable characters (ASCII or Unicode), split into lines. Readable in a simple editor like Notepad, and not tied to any system or application
  • Binary files - e.g. .jpg images, .doc files. Not human-readable without the right software, and tied to a system or application

Python processes text files sequentially, from beginning to end, in either read-only or write-only mode.

Reading a File

Always the same three steps: open, read/write, close. open gives you a file object (think of it as a pipe to the file), stored in a variable you name.

readline.py
# Reading one line at a time with readline()
textfile = open("notes.txt", "r")   # "r" = read only
count = 0
line = textfile.readline()
while line != "":                  # readline() gives "" at the end of the file
    count += 1
    line = textfile.readline()
textfile.close()
print(count, "lines")

read() reads the whole file into one string, and readlines() reads it all into a list of lines - fine for small files.

The better way: a file iterator

iterator.py
with open("notes.txt", "r") as textfile:
    count = 0
    for line in textfile:   # each time round, line is the next line of the file
        count += 1
print(count, "lines")

with wraps the file code and opens and closes the file for you (the close is invisible), so it's neater and you can't forget to close it.

Critique

This code crashes if the file can't be found, can't be opened (corrupted?) or can't be read (not text?). To handle that we need exception handling, which is coming later.

Writing and Appending

ModeMeaning
"r"read only
"w"write only - erases whatever was in the file before
"a"append - adds to the end and keeps the old contents
"b"binary (non-text) files, e.g. "rb"
powers.py
# Write a file of powers of numbers
with open("powers.txt", "w") as outfile:
    for i in range(1, 11):
        outfile.write(str(i) + " " + str(i ** 2) + " " + str(i ** 3) + "\n")

write() only takes strings, and doesn't add a new line for you, so add "\n" yourself. Each write goes after the last one.

append.py
with open("powers.txt", "a") as outfile:
    outfile.write("This line goes on the end\n")

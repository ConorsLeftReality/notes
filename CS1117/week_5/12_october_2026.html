While Loops vs For Loops

Note

No notes were taken in this lecture, so this page was written up from the slides afterwards. Most of the code on the slides is in images, so the examples here are written to match them.

Rule of thumb: use a while loop when you're not sure how many times the code needs to run (an indefinite loop), and a for loop when you want to repeat it a set number of times.

while_syntax.py
while condition:
    body
  • The condition is a Boolean expression, just like in an if statement
  • The body keeps running as long as the condition is True. When it becomes False, the loop stops
  • The condition is checked at the top of the loop (a pre-test), so if it's False to begin with, the body never runs at all

The Control Variable and Infinite Loops

counting.py
i = 0            # set up the control variable before the loop
while i <= 10:
    print(i, end=" ")
    i += 1       # same as i = i + 1 - change it every time round

i is the control variable (you can call it anything). You have to set it up before the loop and change it inside the loop, otherwise the condition never changes.

Infinite loops

If you forget the i += 1, i stays 0, the condition i <= 10 is always True, and the loop never ends. If you get stuck in one: press Ctrl+C first, then Ctrl+Alt+Delete if that doesn't work, then fix your program!

Examples

Letting the user choose the limit

counting4.py
print("Printing even numbers")
limit = int(input("Provide the last number >>> "))
i = 0
while i <= limit:
    print(i, end=" ")
    i += 2

Bouncing ball

Ask for a starting height. The ball bounces to half its height each time. Print each rebound, stopping once the ball is 1mm (0.001m) or less off the ground.

bouncingBall.py
SMALL_NUMBER = 0.001   # 1mm in metres

print("This program computes the number and height of the rebounds of a dropped ball")
height = float(input("What is the starting height? "))
bounce_count = 0

while height >= SMALL_NUMBER:
    height = height / 2
    bounce_count += 1
    print("Rebound #", bounce_count, ":", round(height, 6), "m")

Starting at 10m this prints 14 rebounds, from 5.0m down to 0.00061m.

Mobile data warning

Keep asking how much data was used today, subtracting it from what's left, until you hit the warning level - then say whether you were warned in time.

DataUsage.py
available_data = int(input("How much data did you purchase? "))
warning_level = int(input("When would you like to trigger a warning? "))

while available_data > warning_level:
    usage_today = int(input("How much did you use today? "))
    available_data -= usage_today   # same as available_data = available_data - usage_today
    print("You have " + str(available_data) + "MB left.")

if available_data <= 0:
    print("OOPS you used up your data before I could warn you.")
else:
    print("WARNING you are about to reach your usage limit")

Accumulators

An accumulator is a variable that stores a result as you go round a loop, e.g. a running total. Give it a meaningful name.

factorial.py
factorial = 1      # accumulator starts at 1 for multiplying (0 for adding)
i = 1
while i <= 5:
    factorial *= i
    i += 1
print(factorial)   # 120, which is 1*2*3*4*5

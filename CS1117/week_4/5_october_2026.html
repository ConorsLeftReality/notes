Lists - summary from the slides

  • A list holds multiple items (elements), which can be different types: my_list = [10, 20, "hi", 4.5]
  • Indexing starts at 0. my_list[-1] is the last element, -2 the second last. A bad index raises an IndexError
  • len(my_list) gives the number of elements, so the last index is len(my_list) - 1
  • Lists are mutable: my_list[1] = 99 changes an element in place
  • + (or +=) concatenates two lists; * repeats one, e.g. [0] * 3 gives [0, 0, 0]
  • Slicing: my_list[start:end] gives a new list from start up to but NOT including end. Leave out start/end to go from the beginning/to the end; a third value is the step
  • item in my_list / item not in my_list give True/False

Useful list methods and functions

  • append(x) - add x to the end
  • insert(i, x) - insert x at index i
  • index(x) - index of the first x (ValueError if it's not there)
  • remove(x) - remove the first x
  • sort() / reverse() - sort ascending / reverse the order, in place
  • del my_list[i] - delete the element at index i
  • min(my_list) / max(my_list) - smallest / largest item

## Card deck

def createDeck():
    deck = []
    
    suits = ["s","h","d","c"]
    special_cards = ["J","Q","K","A"]
    
    for suit in suits:
        for i in range (2,11):
            deck.append(f"{i}{suit}")
        for special_card in special_cards:
            deck.append(f"{special_card}{suit}")
    
    return deck

deck_of_cards = createDeck()

for card in deck_of_cards:
    if "h" in card or "d" in card:
        if "A" in card:
            print(f"\033[0;31m{card}")
        else:
            print(f"\033[0;31m{card}",end=" | ")
    else: 
        if "A" in card:
            print(f"\033[0;30m{card}")
        else:
            print(f"\033[0;30m{card}",end=" | ")

Flow Instructions: Branching

Sometimes the flow of control is from one process to the next, but you can change the flow of control using branching.

Branching is normally done using jumps. There are different types of jumps, and these jumps look at the condition of flags in the Status Register (SR)

We are interested in 3 flags in the Status Register (SR)

  • 'Z' Flag - Set if most recent calculation gave a zero result (Pronounced Zero)
  • 'S' Flag - Set if most recent calculation gave a negative result (Pronounced Sine/Sign?)
  • 'O' Flag - Set if most recent calculation gave a result too big (Pronounced Overflow, as its the overflow flag)

Uses of the flags

  • Equality and Inequality can be tested with the 'Z' flag (if raised or not raised)
  • The 'S' Flag can determine if one number is bigger than the other

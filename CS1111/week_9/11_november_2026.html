CALL and RET

A subroutine is a bit of code you write once and use loads of times (like a function)

  • call 70 - pushes the return address (the next instruction) onto the stack, then jumps to address 70
  • ret - pops the return address off the stack back into the IP, so we carry on after the call
  • org 70 - assembler directive: put the following code at address 70
callRet.asm
mov al, 30   ; ASCII '0'
call 70      ; subroutine call
mov [c0], al
call 70
mov [c0], al

org 70       ; subroutine code
add al, 1
ret

end

Traffic Lights with a Delay Subroutine

Pass the length of the delay in by setting BL before the call

trafficLightsWithSubroutine.asm
start:
  mov al, 84   ; red-green
  out 01
  mov bl, 80   ; delay length
  call 70
  mov al, 48   ; amber-amber
  out 01
  mov bl, fa
  call 70
  jmp start

org 70         ; delay subroutine
loop:
  inc bl
  cmp bl, 00   ; count up until bl overflows to 0
  jnz loop
  ret

end

Much shorter and easier to read than copying the delay code everywhere

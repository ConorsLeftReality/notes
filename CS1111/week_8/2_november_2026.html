The Status Register

Lecture 13 was just a review of the slides so far. This one is about making decisions

The Status Register (SR) remembers what just happened:

  • Z (zero) - set if the result was 0
  • S (sign) - set if the result was negative
  • O (overflow) - set if the result was too big for the register (outside -128 to 127)

CMP and Conditional Jumps

cmp subtracts its operands without storing the result, it only sets the flags

  • equal: Z is set
  • second operand bigger: S is set
  • first operand bigger: no flag set

Then jump based on the flags: jz / jnz, js / jns, jo / jno

constrainedWriteToVDU.asm
; write ASCII values to the VDU, wrapping back to C0
mov al, 00
resetToStartOfVDU:
   mov bl, C0      ; bl holds the start of the VDU
writeLoop:
   mov [bl], al
   inc al
   inc bl          ; order matters!
   jz resetToStartOfVDU   ; bl wrapped FF -> 00, so reset it
   jmp writeLoop
end

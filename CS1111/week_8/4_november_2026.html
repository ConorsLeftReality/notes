Ports

The Samphire simulator uses the IN and OUT instructions to get input from, and to send output to, a specified Port.

For Example:

  • IN 00 - Gets the input from Port 00 (mapped to keyboard in samphire) and places the input into the AL register (by design)
NOTE

The input coming from the keyboard will be in ASCII, so pressing 1 on the keyboard will place 31 (hex) in the AL register.

From ASCII to Integer

To work with numbers rather than characters, subtract the ASCII code for '0' (30 hex) from the character you read. E.G. pressing '1' gives 31, and 31 - 30 = 1.

Adding two numbers from the keyboard: read each character, convert both to integers, add them, then add 30 back to turn the result into a character for the VDU (assuming the result is ≤ 9).

Reading a 2-Digit Number

E.G. to read '2' then '3' as the integer 23:

  1. Read the first character and convert it to an integer
  2. Multiply it by 10
  3. Read the second character and convert it to an integer
  4. Add the two together

Writing a 2-Digit Number to the VDU

  1. Divide a copy of the number by 10 - this is the number of tens
  2. Add 30 to convert it to ASCII and write it to the VDU
  3. Use mod 10 on the original number to get the remainder - the number of units
  4. Add 30 and write that to the VDU too

Stack

A stack works the same as a pile of plates. The first plate put into a stack is the last one to be taken out, and the last plate put into a stack is the first one to be taken out.

Rather than choosing random memory locations as temporary places to store values being copied between registers, it is better practice to use the stack

A stack uses 2 (main) commands

  • push al - put the contents of AL onto the stack
  • pop bl - places the value on the top of the stack into the BL register.

The stack will be explained in more detail later.

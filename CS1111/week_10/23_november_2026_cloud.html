Cloud Computing

The NIST definition: cloud computing gives on-demand network access to a shared pool of configurable resources (servers, storage, applications, bandwidth...) that can be handed out and released quickly, with very little management effort

The cloud is made up of 5 essential characteristics, 3 service models and 4 deployment models

5 Essential Characteristics

  • On-demand self-service
  • Broad network access
  • Resource pooling
  • Rapid elasticity
  • Measured service

3 Service Models

  • SaaS (Software as a Service) - you use the provider's apps, usually through a browser. You don't manage anything underneath, e.g. Gmail, Google Photos, Instagram
  • PaaS (Platform as a Service) - you deploy your own app onto the provider's platform (languages, databases, servers). You control your app, not the OS or network, e.g. hosting your own site
  • IaaS (Infrastructure as a Service) - you get the raw resources (virtual machines, storage, networks, firewalls, load balancers) and can run anything, including your own OS

4 Deployment Models

  • Private - for one organisation only
  • Community - shared by organisations with the same concerns (security, policy, compliance)
  • Public - open to the general public
  • Hybrid - two or more of the above joined together, e.g. bursting from private to public when busy

Hardware Virtualisation

Hardware used to run one OS at a time. Cloud servers now run multiple operating systems at the same time on one physical server, using virtualisation (with extra support built into the hardware)

  • Host - the physical server (CPU, memory, disk drives)
  • Hypervisor - software that creates and runs the virtual machines, and keeps them isolated from each other
  • Virtual machines (guests) - software emulations of a whole computer, each with its own OS

Advantages

  • Cheaper - several systems on one server, so less space and power
  • Easier backup and recovery
  • Easier to manage - software is easier to look after than lots of hardware, so less downtime
  • Running VMs can be moved between servers to spread the load
  • Service Level Agreements give admins fine control over resources

Disadvantages

  • Cost - you need decent hardware to support virtualisation in the first place
  • Security - the provider controls the servers, so you can feel disconnected from your data
  • Availability - the provider can go offline unexpectedly

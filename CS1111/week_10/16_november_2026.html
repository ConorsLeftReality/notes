The Operating System Machine Level

The OS level sits on top of the ISA level. It has nearly all the ISA instructions plus new ones called system calls (e.g. read from a file)

  • System calls are interpreted - the OS carries them out step by step
  • Normal ISA instructions run directly on the hardware

Not every computer has an OS - a microwave just runs one simple program forever

What an OS does

  • Manages the hardware and software resources (CPU, memory, disk...)
  • Gives apps a consistent way to use the hardware (an API), so they work on different machines

Six jobs: processor, memory, device and storage management, plus the application interface and user interface

Processor management = making sure every process gets enough CPU time, while wasting as few cycles as possible

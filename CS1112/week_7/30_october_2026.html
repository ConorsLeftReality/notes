Relations on a Single Set - Lecture 9

A relation from a set to itself (R ⊆ A × A) is called homogeneous. We draw them as dots with arrows (a directed graph)

  • Reflexive - everything is related to itself (a self-arrow on every dot), e.g. ≤
  • Anti-reflexive - nothing is related to itself, e.g. <
  • Symmetric - if aRb then bRa (all arrows 2-way), e.g. "is married to"
  • Anti-symmetric - no 2-way arrows between different things, e.g. "is a parent of"
  • Transitive - if aRb and bRc then aRc

Equivalence relation = reflexive + symmetric + transitive. It splits the set into groups (equivalence classes)

The identity relation relates everything to itself and only itself

Order Relations - Lecture 10

An order is anti-symmetric + transitive (based on < for numbers). Used for things like ranking holidays or which tasks must come first

  • Strict order - also anti-reflexive, e.g. <
  • Total order - every pair is ordered one way or the other, e.g. ≤ on numbers
  • Partial order - some pairs aren't comparable, e.g. ⊆ on sets

A Hasse diagram draws a partial order with only the minimum arrows needed - the rest come from transitivity

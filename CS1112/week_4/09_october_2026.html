Functions I

What are Functions?

Think of a function as a machine, you feed it an input, it does some work and spits out an output. Functions are the same.

Functions in computer science are the same as functions in maths (E.G. sin(x), cos(x*2), tan(x-3), etc etc)

A function f from A to B specifies for each element of A exactly one element of B.

If f : A → B, then A is the domain, and B is the codomain.

What properties must functions have

  • Every domain element has a partner in the codomain
  • No domain element has two or more partners

Standard Function Concepts

  • A function f: R→ R is linear if f(x) can be written f(x) = ax+b for some fixed integers a and b.
  • A function f: R → R is polynomial if f(x) can be written f(x) = a1xn + a2xn-1 + ... + an-1x + an for some fixed integers n and a1, a2, ..., an.
  • A function f : R →R is exponential if f(x) contains a term ax for some fixed integer a.

REMINDER

Let A and B be two non-empty sets. A function f from A to B specifies for each element of A exactly one element of B. We write f : A → B, and if f specifies b for a, we write f(a)=b, or f : A → B : a |→ b

Properties of Functions

Consider a function f:A→B If f(a) = b, then b is the image of a under f. The range of f is the subset of B to which elements of A are mapped.

Types of Functions

  • Surjective (onto) - (all codomain used) Every element of the codomain is the image of at least one element of the domain, i.e. the range = the codomain
  • Injective - (One to One, doesnt need all codomain used) If and only if no two elements of the domain map onto the same element of codomain.
  • Bijective - (Full domain & codomain used, and ONLY one to one relationships.) If and only if the function is BOTH surjective and injective.

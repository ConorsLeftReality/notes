What is a set?

A set is a collection of things (the things can be anything)

The things dont matter, what matters is that we state precisely and clearly what "things" are in the collection.

NOTE - A set must use curly brackets, MUST

- TO WRITE A SET, use curly brackets, and separate items with commas

Specifying a set

  • For simple sets, we write down each thing in a list
  • This style of writing sets is known as set enumeration, or set display, or extensional definition
  • Sometimes, when the pattern is clear, we will write the first few items, three dots, then pick up again from a point in a set further on

Specifying more complex sets

specifying more complex sets, we specify a template, then a rule, such that everything that matches the template and obeys the rule is in the set

Examples

{y | y is a library book with 'databases' in the title}

{x | x is a woman resident in Co. Cork, registered with the health service and over 55}

Set Membership

In order to talk about sets, we need more formal notation. Let A be the name of a set, and let x be some thing.

  • x is a member of A: x ∈ A
  • x is NOT a member of A: x ∉ A

Set notation and membership

Examples (from the slides):

  • CS1112 ∈ {CS1106, CS1110, CS1112, CS1115, CS1117} - true
  • 7 ∈ { y | y is a single digit } - true
  • Galway ∉ {z | z is a county in Munster} - true (Galway is in Connacht)
  • clare ∈ {cork, clare, limerick, waterford, tipperary} - true

A definition using a template and rule (like {x | x is an even integer}) is called an intensional definition. It doesn't matter which letter you use in the template, as long as the rule is clear.

Two most important properties of sets

The order in which you write down the elements in an enumeration doesnt matter

There is only one copy of each element in a set, so repeated elements in an enumeration are ignored.

Equal sets

Two sets are equal if both sets are identical

Two sets are not equal if one or more elements are different

Some important sets

Null set (contain nothing) - {}, ∅

Set that contains something, that is nothing - {∅}

-- TWO DIFFERENT THINGS --

Set Z - Set of integers (whole pos/neg numbers)

Set Q - Rational numbers (can be expressed as a fraction)

Set R - Set of real numbers (such as π or √2)

Subsets

Sometimes we have sets that are contained within another set

E.G.

A = {1,2,3,4}

B = {-1,0,1,2,3,4,5,6,7}

A ⊆ B

Note: A and B are different sets, but B contains all the elements in A, therefore A is a subset of B

Proper Subsets

A is a proper subset of B if A ⊆ B and A ≠ B, written A ⊂ B

Set Union

A set union of two sets is a new set consisting of every member of the two sets.

E.G. A = {x,y,w}, B = {y,z} → A ∪ B = {x,y,w,z}

Set Intersection

A set intersection of two sets is a new set consisting of members in both sets (common elements)

E.G. A = {x,y,w}, B = {y,z} → A ∩ B = {y}

Set difference

The set difference of two sets is a new set consisting of each element of the first that is NOT an element of the second.

E.G.

A = {x,y,w} , B = {y,z}

A \ B = {x,w}

Sets and Collections (Cont.)

Set Complement

The set complement of a set is a new set consisting of every element of the universal set that is NOT an element of the first set

E.G.

A = {x,y,w} , B = {y,z}, U = {p,x,y,w,z}

A' = {p,z}

NOTE: A' = U \ A

For X in U, x element of A' if and only if x not element of A

Set Cardinality

The cardinality of a finite set is the number of elements in the set

E.G.

A = {a,b,c,d}

|A| = 4

Set theory - cont.

We can mix and match the elements - they do not have to be of the same type

E.G.

S = { a , {b} , c , {} , {d,e} }

SO: a element of S, c element of S, {b} element of S, {} element of S, {d,e} element of S

BUT: b NOT element of S, ∅ NOT element of S, d NOT element of S, e NOT element of S

Power Set

The Power Set is the set of all possible subsets of A (all possible combinations of elements in a set)

Power set of A is written as P(A)

For any A, |P(A)| = 2**|A|

Set Partition

A partition of a set A is a division of all the members of A into non-empty, non-intersecting subsets

E.G.

Set A = {1,2,3}

A possible partitioning of A is { {1}, {2,3} }

Another possible partitioning of A is { {1}, {2}, {3} }

THE FOLLOWING IS NOT A POSSIBLE PARTITIONING: { {1,2,3}, {} }

Set Operations

Like maths, set operations can have different outputs based on order. KEEP IN MIND (and brackets count too)

Union and intersection are associative

Set difference is NOT associative

Intersection distributes over union: A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)

- One operation can be distributed over multiple things, like A * (B+C) == A*B + A*C in normal maths

Union distributes over intersection: A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)

De Morgan's Laws - IMPORTANT (Double negative, I don't want this one AND I don't want that one)

  • (A ∪ B)' = A' ∩ B' - not in (A or B) means not in A and not in B
  • (A ∩ B)' = A' ∪ B' - not in (A and B) means not in A or not in B

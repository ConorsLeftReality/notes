CSS Selectors

Before we go through selectors, revise CSS terminology here.

The two kinds of CSS selectors

  • Find Selectors - which are covered in detail this module
  • Filter Selectors - which we will cover briefly

KNOW FIND SELECTORS IN CHRISTMAS EXAM, THEY WILL SHOW UP, NO FILTER SELECTORS IN THE EXAM

FIND SELECTORS (in our syllabus)

Selector Description
* Matches all elements
E Matches all elements with tag name E
#I Matches the element with id of I
.C Matches all elements with class of C
E > F Matches all F elements that are children of E elements
E F Matches all F elements that are descendants of E elements
E + F Matches all F elements that are immediately preceded by sibling E
E ~ F Matches all F elements preceded by sibling E

Find Selectors

* selector

The * selector selects all elements

'E' selector

Given an element with the tag name of 'E', the CSS applies to that element and any valid children

NOTE

* selects every single element, and 'body' would just apply to body. If border was used (non-inheritable), then the outputs are different. (Body does not inherit borders, but * will put a border on EVERYTHING)

# elements

Any elements that start with a # indicate that the CSS is applying to a specific ID (e.g. #section-id matches to HTML id="section-id")

NOTE: IDs must be unique

. elements

Any CSS thats selector starts with . matches with all elements in a Class (e.g. .class_name matches to HTML class="class_name"

In HTML, a class is a way of grouping specific elements together. (e.g. video games in a HTML file formatted with <i class="video-game">Game Name</i> will be in the group of video games)

NOTE

The difference between classes and id is that class SHOULD be repeadely mentioned, and id SHOULD only be mentioned once. Why? FUCK YOU THATS WHY KEEP FUCKING READING

To avoid id-itis (or class-itis), just use these selectors.

Children selectors

Read these selectors as if it was arabic.

e.g. section > p

Meaning: CSS selects paragraphs WHERE the parent is a section

THEREFORE, this selector matches all elements that are children of another specified element

Descendant Selectors

Again, read as arabic (according to Derek, which makes sense)

e.g. E F

Meaning: CSS selects all elements F that are descendants of elements E

Filter Selections - NOT IN EXAM

There are three ways to combine a find selector with a filter.

  • Attribute selectors — in square brackets, e.g.
    • E[foo] - finds E elements that have an attribute foo.
  • Pseudo-classes — after a colon, e.g.
    • E:first-child - finds E elements that are the first child of their parent.
  • Pseudo-classes — after a colon, e.g.
    • E:first-child - finds E elements that are the first child of their parent.
    • E:hover - finds E elements, but only when the user hovers over them with the mouse.
  • Pseudo-elements — after two colons, e.g.
    • E::first-letter - finds the first letter of E elements.

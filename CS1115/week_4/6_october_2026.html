URL - Fragment

A Fragment is a part of a URL that brings you to different sections of a singular webpage (Similar to the Contents at the top of this page)

Fragments are assigned using id attributes (Global attribute, so can be used on any element)

id attributes must be unique, so dont use multiple with the same name.

A section can be referenced using <a href="#fragment-id">. The hashtag is important for referencing the sections

example_code.html

<a href="#fragment-id">Click here to go to *blah* section<a>

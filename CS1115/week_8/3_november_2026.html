Box Model - Padding

PREREQUISITES

Before continuing, know the box model, box-sizing and width

Padding - Space between content and border

example_padding.css
p {
    padding-top: 0.5em; 
    padding-right: 1em; 
    padding-bottom: 0.5em; 
    padding-left: 1em;
}

/* OR, USE BELOW FOR SHORTER */

/* Clockwise (top, right, bottom, left) */

p {
    padding: 0.5em 1em 0.5em 1em;
}

/* Top and Bottom, then Left and Right */

p {
    padding: 0.5em 1em;
}

/* Same size for all sides */

p {
    padding: 0.5em;
}
NOTE

color only affects the text. background-color (and background-image) affect the content AND the padding, but not the border or margin.

Colours

In CSS, we have many ways to assign colour values

  • Named Colours - There are 148 colours that have names (check w3schools)
  • RGB - We can assign colors to RGB values with color: rgb(0-255 0-255 0-255), as long as the values are between 0 and 255
  • Hexadecimal - We can also assign colours to a 6 figure Hexadecimal number. color: #000000 to color: #FFFFFF
  • RGBa Values - A fourth channel, the alpha channel, can specify transparency. rgb(0-255 0-255 0-255/0(transparent) to 1(fully opaque))
  • HSL - Hue, Saturation and Lightness (hue between 0 and 360, saturation is a percentage and lightness is a percentage)

Background Images

Background Images can also be used. These show behind the content AND the padding

By default, the background image tiles. We can stop this with background-repeat:

  • no-repeat; - Stops the tiling
  • repeat; - Allows tiling
  • repeat-x; - Repeats on the X axis
  • repeat-y; - Repeats on the Y axis

We can also position the background in the box with background-position:

  • top; - Top of the box
  • top left; - Top Left of the box
  • bottom; - Bottom of the box
  • center; - Centered in the box
  • and a fuckton more

background-attachment: scroll; allows the image to move as you scroll, but background-attachment: fixed; allows the background image to stay still.

background-size: contain; scales the image so all of it fits inside the box (some of the box may be left uncovered), and background-size: cover; scales it so the whole box is covered (some of the image may be cut off)

Background colours display behind background images, which display behind the content. There's also a background shorthand property that sets them all at once.

Box Model - Borders

For Borders, you must specify colour, width and style

example_border.css
p {
    border-width: 1px; 
    border-style: solid; 
    border-color: black;
}

/* OR MORE SIMPLY */

/* width, style, colour */
p {
    border: 1px solid black;
}

There are many styles of borders, so GO LOOK ONLINE

  • Horizontal offset: positive = shadow on the right, negative = on the left
  • Vertical offset: positive = shadow below, negative = above

  • Shadows don't change the total size of the box

Box Model - Margin

The Margin is the space outside of the box

example_margin.css
p {
    margin-top: 1em;
    margin-right: 2em; 
    margin-bottom: 1em; 
    margin-left: 2em;
}

/* OR, SHORTER BELOW */

p {
    margin: 1em 2em 1em 2em;
}

BUT, margin collapsing happens. Adjacent bottom and top margins don't add up: if a box has a bottom margin of 5px and the box below has a top margin of 10px, the gap is 10px, not 15px (the smaller margin is eliminated)

As with padding, percentage margins are based on the width of the element's parent.

Awkward Exceptions

For inline non-replaced elements (e.g. <em>), like the last lecture mentioned:

  • Setting the width/height has no effect
  • Setting the top/bottom padding/margin won't push other boxes away
  • Use display: inline-block; to change this

Box Model - Padding

PREREQUISITES

Before continuing, know the box model, box-sizing and width

Padding - Space between content and border

example_padding.css
p {
    padding-top: 0.5em; 
    padding-right: 1em; 
    padding-bottom: 0.5em; 
    padding-left: 1em;
}

/* OR, USE BELOW FOR SHORTER */

/* Clockwise (top, right, bottom, left) */

p {
    padding: 0.5em 1em 0.5em 1em;
}

/* Left and Right, then Top and Bottom */

p {
    padding: 0.5em 1em;
}

/* Same size for all sides */

p {
    padding: 0.5em;
}
NOTE

When change the background color, you change both the content and the padding. But, background only affects the background of the content

Colours

In CSS, we have many ways to assign colour values

  • Named Colours - There are 148 colours that have names (check w3schools)
  • RGB - We can assign colors to RGB values with color: rgb(0-255 0-255 0-255), as long as the values are between 0 and 255
  • Hexadecimal - We can also assign colours to a 6 figure Hexadecimal number. color: #000000 to color: #FFFFFF
  • RGBa Values - A fourth channel, the alpha channel, can specify transparency. rgb(0-255 0-255 0-255/0(transparent) to 1(fully opaque))
  • HSL - Hue, Saturation and Lightness (hue between 0 and 360, saturation is a percentage and lightness is a percentage)

Background Images

Background Images can also be used. These show behind the content AND the padding

By default, the background image tiles. We can stop this with background-repeat:

  • no-repeat; - Stops the tiling
  • repeat; - Allows tiling
  • x-repeat; - Repeats on the X axis
  • y-repeat; - Repeats on the Y axis

We can also position the background in the box with background-position:

  • top; - Top of the box
  • top top; - Top Left of the box
  • bottom; - Bottom of the box
  • center; - Centered in the box
  • and a fuckton more

background-attachment: scroll; allows the image to move as you scroll, but background-attachment: fixed; allows the background image to stay still.

background-size: contain; makes the image fit within the border, and background-size: cover; fills the box with the image

Box Model - Margin

The Margin is the space outside of the box

emxaple_margin.css
p {
    margin-top: 1em;
    margin-right: 2em; 
    margin-bottom: 1em; 
    margin-left: 2em;
}

/* OR, SHORTER BELOW */

p {
    margin: 1em 2em 1em 2em;
}

BUT, margin collapsing happens. Say a box has a margin of 1em, and the box below has a margin of 1em. These margins between the boxes wont be combined into 2em, but will be 1em due to margin collapsing

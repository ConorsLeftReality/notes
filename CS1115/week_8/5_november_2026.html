Page Layout - Intro

Recall that pages have either fixed-width or liquid layouts. Multicolumn page layouts, with two or three columns, are very common

Do not make these with methods such as floating or positioning, use floating and positioning carefully.

Do make these with flexbox layouts to follow modern CSS.

Layout

We can distinguish

  • Macro layout - page layout
  • Micro layout - component layout

There may be a layout for the page and seperate layouts for the components on the page.

CSS Layouts

Flow layout: Based on the outer display type of each element.

Flexbox: One-dimensional layout based on rows OR columns but elements can 'flex' to fill additional space or shrink to fit smaller spaces.

Grid layout: Two-dimensional layout (rows AND columns).

Other: floating, positioning, multicolumn text. (use carefully)

Different sections of a webpage can use different layout methods.

Responsive Web Design (RWD)

In RWD, we adapt the layout to the characteristics of the device or window. (Page layout and/or component layout can narrow or widen depending on the device/window)

CSS Flexbox

A flexbox contains items, which are laid out in a one-dimensional way, either in rows or in columns.

The items in the flexbox can 'flex', grow or shrink.

Don't use flexbox when flow layout is sufficient!

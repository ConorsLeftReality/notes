Page Layout - Intro

Recall that pages have either fixed-width or liquid layouts. Multicolumn page layouts, with two or three columns, are very common

Do not make these with methods such as floating or positioning, use floating and positioning carefully.

Do make these with flexbox layouts to follow modern CSS.

Layout

We can distinguish

  • Macro layout - page layout
  • Micro layout - component layout

There may be a layout for the page and separate layouts for the components on the page.

CSS Layouts

Flow layout: Based on the outer display type of each element.

Flexbox: One-dimensional layout based on rows OR columns but elements can 'flex' to fill additional space or shrink to fit smaller spaces.

Grid layout: Two-dimensional layout (rows AND columns).

Other: floating, positioning, multicolumn text. (use carefully)

Different sections of a webpage can use different layout methods.

Responsive Web Design (RWD)

In RWD, we adapt the layout to the characteristics of the device or window. (Page layout and/or component layout can narrow or widen depending on the device/window)

CSS Flexbox

A flexbox contains items, which are laid out in a one-dimensional way, either in rows or in columns.

The items in the flexbox can 'flex', grow or shrink.

Don't use flexbox when flow layout is sufficient!

Flexbox Properties

A complete guide to Flexbox can be found here.

Turn an element into a flexbox with display: flex; on the container.

Parent properties (the flexbox / container) Child properties (the flex items)
flex-directionorder
flex-wrapflex-grow
justify-contentflex-shrink
align-itemsflex-basis
align-contentalign-self
flexbox_example.css
.parent {
    display: flex;
    flex-direction: row;
    flex-wrap: nowrap;
    justify-content: flex-start;
    align-items: flex-start;
}

.child {
    flex: initial;
}
  • flex: initial - items keep their default size and don't grow
  • flex: auto - items can grow, but bigger items get more of the space
  • flex: 1 - items can grow, and they share all the space equally

justify-content distributes spare space in the flex direction, and align-items distributes it in the other direction.

With flex-wrap: wrap, items move onto new rows when they run out of room, but don't expect them to line up in columns with the rows above (unless you fix their sizes). If you want that, use grid layout.

CSS Grid Layout

Grid Layout makes two-dimensional layouts easy(/easier)

A grid contains items arranged in columns and rows

HERE IS A COMPLETE GUIDE TO GRID LAYOUT

Grid terminology: lines, tracks (a row or column), areas and cells

grid_example.css
.parent {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
    gap: 1em;
}

fr = a fraction of the free space. Other values for grid-template-columns:

  • 1fr 2fr 1fr - middle column twice as wide
  • repeat(4, 1fr) - four equal columns
  • 3fr repeat(2, 1fr)
  • repeat(auto-fill, 20em) - as many 20em columns as fit
Classic Mistake

Grid and flexbox only place their children, not grandchildren. To place grandchildren, put display: contents; on the children, which removes them from the tree as if the grandchildren were children.

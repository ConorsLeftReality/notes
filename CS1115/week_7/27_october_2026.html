Filters

What do these select?

  • .ingredient:first-child
  • .ingredient:first-child + .ingredient

ANSWER

  • Any item of class ingredient IF its a first child
  • Any item of class ingredient IF its a first child AND has a preceding ingredient

Today's Lecture

Conflicts

Often, the same element may be selected by more than one rule

Sometimes, the two rules can conflict E.G. p { color: green } followed by p { color:red }

NOTE

For a given proeprty, two or more CSS rules select element and set different values

What happens? Another cliffhanger, wait until later

NOTE

Sometimes, the conflict can be obvious, but more often than not, the conflict isnt obvious.

ANOTHER NOTE, more often than accidental conflicts, we often use conflicts because they can lead to more consise stylesheets

Resolution of Conflicts

Resolution uses 3 criteria, taken in this order

  1. Origin
  2. Specificity
  3. Ordering

Note: this is a simplified explanation

(1) Origin

CSS rules have different origins

  • Author Stylesheets: the ones we write
  • User-Agent Stylesheets: the browser's default stylesheet

It is because of the user-agent stylesheet that...

  • em & i elements are in italic;
  • strong, b & h1-h6 elements are bold;
  • h1 headings are bigger than h2 headings;
  • consecutive paragraphs are separated by a blank line;
  • and more.
Stylesheet Origin Conflicts - What happens?

If two rules conflict and one is from an author stylesheet and the other is from the user-agent stylesheet, then the author stylesheet wins.

(2) Specificity

If origin does not resolve a conflict, then we turn to specificity

Roughly,

  • Selecting by id is the most specific.
  • Selecting by class is the second most specific.
  • Then, a selector that is longer is more specific.

Note: * and combinators, such as space, >, +, ~, have no effect on specificity.

(3) Ordering

If origin and specificity do not resolve a conflict, then we turn to ordering

The later rule wins

NOTE

Considering ordering, inline stylesheets are though of as coming later than embedded stylesheets, which come later than external stylesheets.

The Cascade

Note the way that conflict resolution cascades:

  1. origin
  2. to specificity
  3. then to ordering

BUT KEEP IN MIND, this is only the cases of conflict

A classic mistake is to use the cascade when you should instead use inheritance and the blocking of inheritance

Exploiting Stylesheets

CSS experts exploit blocking of inheritance and conflicts to get a more elegant stylesheet.

E.g. Suppose we want all i elements to be blue, except ones referring to video games, which should be red.

A conflict is the natural solution

conflict.css
i {
    color: blue;
}
    
.game {
    color: red;
}

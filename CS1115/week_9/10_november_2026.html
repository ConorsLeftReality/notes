More Aligning

Aligning the content of a box

We can align THE CONTENT OF A BOX in relation to the parent element using text-align:

  • left
  • right
  • center

Even though its called text-align, it acts on the CONTENT of a box

Aligning the block itself

To center a single element whose display is block horizontally within a parent element, set its left and right margin to auto with margin-left:auto; and margin-right:auto; (common shorthand: margin: 0 auto;)

Nothing will happen unless the element is narrower than its parent!

The same trick is often used to center the whole page:

centering_the_page.css
html {
    background-color: white;
}

body {
    width: 80%;
    margin: 0 auto;
    background-color: green;
}

Centering Several Elements

To center several elements horizontally within a parent element, use a flexbox and justify-content

centering_several_elements.css
.parent {
    display: flex;
    flex-direction:row;
    flex-wrap: nowrap;
    justify-content: center;
    align-items: center;
    gap: 1em;
}
        
.child {
    flex: 1;
}

Styling

Styling a nav

If we want to make a horizontal menu, we can use CSS like this to do so

styling_nav_1.css
nav {
    background-color: gray;
    padding: 1em;
}
        
nav a {
    color: black;
    background-color: white;
    border: 1px solid black;
    padding: 1em;
    text-align: center;
    text-decoration: none;
}

The problem with this is that every box is of different widths, and overflowing the nav bar

A solution for this would be to use flex box to have more fine-control

styling_nav_2.css
nav {
    background-color: gray;
    padding: 1em;
    display: flex;
    flex-direction: row;
    flex-wrap: wrap;
    justify-content: space-between;
    align-items: center;
    gap: 1em;
}
                    
nav a {
    color: black;
    background-color: white;
    border: 1px solid black;
    padding: 1em;
    text-align: center;
    text-decoration: none;
    flex: 1;
}

We can also style further with code like this, to show which box is hovered over, or which page we are already on

styling_nav_3.css
nav a[href=""]
{
    color: rgb(200 200 200);
}

nav a:hover
{
    background-color: rgb(200 200 200);
}

To get a stacked (vertical) menu, change flex-direction: row to column, and swap the values of justify-content and align-items (since the main direction has flipped).

Styling a header

A header with a logo and a title, laid out with a flexbox:

styling_header_1.css
header {
    border: 1px solid black;
    display: flex;
    flex-direction: row;
    flex-wrap: wrap;
    justify-content: flex-start;
    align-items: center;
    gap: 2em;
}

header h1 {
    font-size: 2em;
}

If the header holds an h1 and a nav, use justify-content: space-between to push them to opposite ends. With a logo, h1 and nav, keep flex-start and give the nav margin-left: auto; to push just the nav to the right. The nav itself can be its own flexbox (as above).

Multi-column Page Layouts

Stacked Page Layout

header, nav, main, footer one under the other: CSS flow layout handles this on its own, no extra CSS needed.

Two-column using Flexbox

two_column_flexbox.css
body {
    display: flex;
    flex-direction: row;
    flex-wrap: wrap;
    justify-content: flex-start;
    align-items: center;
}

header { width: 100%; }
nav    { width: 25%; }
main   { width: 75%; }
footer { width: 100%; }

Two-column using Grid

two_column_grid.css
body {
    display: grid;
    grid-template-columns: 1fr 3fr;
    grid-template-areas: "top top"
                         "middle-left middle-right"
                         "bottom bottom";
}

header { grid-area: top; }
nav    { grid-area: middle-left; }
main   { grid-area: middle-right; }
footer { grid-area: bottom; }

The default align-items: stretch isn't great here, so change it.

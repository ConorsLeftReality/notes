Shortcuts

  • ? - show all shortcuts
  • N / SPACE - next slide
  • P / Shift + SPACE - previous slide
  • ← / H - left
  • → / L - right
  • ↑ / K - up
  • ↓ / J - down
  • Alt + arrow - move without stepping through fragments
  • Shift + arrow - jump to first / last slide
  • G - jump to slide
  • ESC / O - slide overview
  • F - fullscreen
  • . - pause (black screen)
  • S - speaker notes view
  • C - draw on the slide
  • B - chalkboard
  • Left click + drag - draw
  • Right click + drag - erase
  • X / Y - next / previous pen colour
  • DEL - clear drawings on this slide
  • BACKSPACE - reset all drawings
  • D - download drawings
  • #/12 at the end of the URL - go to slide 12
  • ?print-pdf at the end of the URL, then Ctrl + P - save all slides as a PDF

Exam Format

90 minutes, 5 questions, 15 marks each, answer ALL (about 18 minutes per question). Non-programmable calculators allowed.

  • Q1 - pick the right HTML tag and justify it
  • Q2 - spot the HTML error, external stylesheets, draw the DOM tree
  • Q3 - web server file system: absolute/relative URLs and which file gets served
  • Q4 - CSS selectors: what does it select and why
  • Q5 - the cascade: explain why a rule wins

Q1 and Q2 - HTML

Tags to choose from were: article, b, div, em, h1, i, p, section, strong, span. See Lecture 9

  • article - self-contained, makes sense on its own (a review, a blog post)
  • section - a themed chunk of a page, usually with a heading
  • strong = importance, em = stress emphasis (changes the meaning when read aloud)
  • b = draw attention with no extra importance (product names), i = different voice (a technical term, a phrase from another language)
  • div / span - no meaning at all, only use when nothing else fits (block / inline)

<link rel="stylesheet" href="styles.css">Stylesheet</link> is wrong because link is a void element: no content and no closing tag.

Advantage of an external stylesheet: one file styles every page on the site, so a change only has to be made once (and the browser can cache it).

DOM tree: html at the top, head and body under it, and every nested tag is a child of the tag it's inside. Text and img are leaves.

Q3 - URLs and Web Servers

See Lectures 5 and 6 and Lecture 7

The 2022 server had DocumentRoot "/www", ErrorDocument 404 /error.html and DirectoryIndex index.html. Files: /www/index.html, /www/error.html, /www/dairy/{index, milk, curd}.html, /www/images/cow.jpg and /meat/beef.html.

  • Files hosted: only things inside the DocumentRoot, so 6 (beef.html is outside /www)
  • Absolute URLs from /www/dairy/index.html: /images/cow.jpg, /dairy/curd.html
  • Relative URLs from the same page: ../images/cow.jpg, curd.html
  • http://www.exam.org/ → /www/index.html (DirectoryIndex)
  • http://www.exam.org/dairy/ → /www/dairy/index.html
  • http://www.exam.org/meat/beef.html → /www/meat/beef.html doesn't exist, so a 404 and /www/error.html is served

Q4 and Q5 - Selectors and the Cascade

See Lecture 11 - Selectors and Lecture 12 - Conflicts

  • A B - B anywhere inside A (descendant)
  • A > B - B directly inside A (child)
  • A + B - B straight after A, same parent (adjacent sibling)
  • A ~ B - any B after A, same parent (general sibling)

2022 examples (milk pudding list): h1 li selects nothing because no li is inside the h1. li > .solid misses cardamom because its parent is a ul, not an li. #B > #H > * > li ~ li picks the 2nd-4th method steps, and the shortest selector for the same thing was .cool.

Who wins a conflict?

  1. A rule that targets the element directly always beats a value it inherits from a parent (even if the parent's rule uses an id)
  2. Then specificity: ids (1,0,0) > classes (0,1,0) > element names (0,0,1). #K beats ul > li > ul > li
  3. Same specificity: the rule that comes last wins
Exam tip

Q5 says "explain why in detail". Say which rules match the element, whether each one is direct or inherited, and the specificity of each.

Making CSS More Dynamic

This lecture looks at the says to make our CSS more dynamic

  • Scroll behavior
  • Hover effects
  • Tranforms, transitions and animations

We can also use JavaScript and animations for this

NOTE

Remember about page jumps, where a user clicks a link and they are moved to somewhere else on the same page

Scroll Behavior

By default, the page scrolls to the anchor for a page jump immediately.

Using scroll-behavior: smooth;, the browser scrolls to the destination over a period of time

An issue with page jumps is that if you use it with a fixed element, the anchor could be hidden behind the fixed element

The solution to this is to use the scroll-margin-top property to offset the top of the anchor scroll

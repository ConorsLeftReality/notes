Out of Flow

By default, elements are laid out in the order they appear in the HTML

There are ways of moving elements so they show up somewhere else, not based on the order of the HTML

  • Some take the element out of flow - the other elements don't know it exists (absolute and fixed positioning)
  • Others leave it in flow - the other elements still know it exists (floating and relative positioning)

Floating

Floating an element...

  • moves it to the left or right within its parent
  • makes its outer display type block, if it wasn't already
  • lets text and other inline content wrap around beside and below it

The main use is for images, but you can float anything. You'll probably want to set a width and give it some margins too

floating_an_image.css
img {
    float: left;
}

CSS Shapes

CSS shapes let the text flow around a shape that isn't a rectangle

The element the text flows around must...

  • be floated left or right, and have a width and height
  • have the shape-outside property, with a value like circle, ellipse, inset (= rectangle) or polygon
shape_circle.css
#shape {
    float: left;
    height: 10em;
    width: 10em;
    shape-outside: circle();
}
  • By default the circle's radius is 50% of the element's width, centred in the middle
  • Change the radius: shape-outside: circle(20%);
  • Change the radius and the centre: shape-outside: circle(20% at 30% 70%);
  • You can add a gap with shape-margin: 2em;
Gotcha

If the shape is bigger than the element, the text flows around the element, not the shape. So 50% is the biggest radius that does anything (and shape-margin can easily cause this too)

Getting rid of the empty div

An empty <div id="shape"> just to make a shape spoils the HTML. Two ways around it:

1. Generated content - make the shape in CSS with ::before

shape_generated_content.css
#seashells::before {
    content: "";
    float: left;
    height: 10em;
    width: 10em;
    shape-outside: circle();
}

2. Use an image - float the image and give it the shape. If the image has a transparent background (alpha channel), you can even use the image itself as the shape

shape_from_image.css
#seashells img {
    float: left;
    shape-outside: url("seashell.png");
}

Note: the image has to be CORS-compatible for this to work

Positioning

CSS positioning lets you put an element exactly where you want it

BUT AVOID IT! (Mostly) People used to lay out whole pages with positioning. Don't, flexbox and grid are way better now

The position property says how it's positioned:

  • static
  • relative
  • absolute
  • fixed
  • sticky

Then the offset properties top, right, bottom, left (any units, px, em, %...) say where it goes. z-index says what goes on top of what

If you set both top and bottom, bottom gets ignored. Same with left and right, right gets ignored

Static

The default, normal layout. The offset properties do nothing

Relative

For nudging an element. The offsets move it from where it would have been, e.g. top: 2em; nudges it down, top: -2em; nudges it up

It's still in flow, so it leaves a gap behind

relative.css
#phrase {
    position: relative;
    top: 2em;
    left: 3em;
}

Absolute

Taken out of flow, so no gap left behind

It's positioned relative to its containing element: the nearest ancestor that isn't static, or if there isn't one, the viewport (the browser window)

The offsets are now the distance from the edges of that containing element

To get it working how you want, you usually set position: relative; on the parent (with no offsets, so the parent doesn't actually move)

absolute.css
#container {
    position: relative;
}

#phrase {
    position: absolute;
    top: 2em;
    left: 3em;
}

Fixed

Like absolute, but always relative to the viewport. It stays put when you scroll

Sticky

Acts normal until you scroll it to a certain distance from the edge of the viewport, then it acts like fixed and sticks there

sticky.css
h1 {
    position: sticky;
    top: 0;
    left: 0;
}

When to actually use it

Putting text over an image (Derek's example was a CENSORED stamp over a picture)

text_over_image.css
#censoredfigure {
    width: fit-content;
    position: relative;
}

#censoredmessage {
    color: red;
    background-color: white;
    border: 2px solid red;
    position: absolute;
    top: 45%;
    left: 25%;
    transform: rotate(-30deg);
}

Fixed headers and footers, so only the main scrolls

fixed_header_footer.css
header {
    position: fixed;
    top: 0;
    left: 0;
}

footer {
    position: fixed;
    bottom: 0;
    left: 0;
}

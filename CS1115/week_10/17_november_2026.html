Text Properties

We can set the properties of text, such as...

  • color: blue;
  • letter-spacing: 1em;
  • line-height: 90%;
  • text-align: right;
  • text-indent: 1em;
  • text-transform: uppercase;
  • word-spacing: 2em;
  • text-decoration: underline;
  • text-shadow: 2px 1px gray;

For example, here is how to make newspaper text (in a very basic form)

newspaperish.css
main {
    column-width: 20em;
    column-gap: 2em;
    column-rule: 1px solid gray;
}
    
main h1 {
    column-span: all;
}
    
figure {
    break-inside: avoid;
}
    
img {
    max-width: 100%;
}

Hyphenation

What if a word is too long for a column? Does it stop, does it continue, does it split itself? Hyphenation is important for this

Either...

  • Set hyphens: manual; and the container, and put &shy; wherever a word can be split in the HTML
  • OR set hyphens: auto; on the container and make sure the container has, or inherits, a lang attribute

Font Properties

Font Sizing

There are also various font properties

  • font-family: "Times New Roman";
  • font-size: 12px;
  • font-style: italic;
  • font-weight: bold;

In CSS, we define the font-size. This can either be absolute or relative font sizing

For sizing, use pixels for :root { font-size: 16px } and use em and rem sizing for other font sizing

Note: YOU DO NOT NEED TO SPECIFY ROOT FONT SIZE

Fonts

  • Some fonts are proportional, others are monospace
  • Some fonts have serifs (with squigly bits); others are sans-serifs (without squigly bits)

A problem that we have is that every person has different fonts on their computer. To account for this, we create a font stack. For example, font-family: Verdana, Geneva, Tahoma, sans-serif;

BUT this isnt what we want, we want to be fancy fucks. We can use @font-face { font-family: MuseoSans; src: url('fonts/museosans-500-webfont.woff2') format('woff2') }

Think about copyright, think about readability

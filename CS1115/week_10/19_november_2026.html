CSS Custom Properties (Variables!)

If you use the same colours everywhere, changing your colour scheme means changing loads of rules. Custom properties fix this, they're basically variables

  • Define them inside a rule, names start with -- (and ARE case-sensitive)
  • Use them with var()
  • JavaScript can change them, e.g. for theme switching
custom_properties.css
html {
    --base-color: black;
    --base-bgcolor: lightgray;
    --main-color: white;
    --main-bgcolor: green;
}

header, nav, aside, footer {
    color: var(--base-color);
    background-color: var(--base-bgcolor);
}

main {
    color: var(--main-color);
    background-color: var(--main-bgcolor);
}

table {
    border: 1px solid var(--main-bgcolor);
}

Use them for a whole theme, not just colours: spacing (margins, padding), borders, fonts and font sizes

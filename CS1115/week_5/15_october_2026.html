What is CSS

CSS, or Cascading Style Sheets, are used to modify a web pages appearance.

The current version is CSS3, specified by W3C

Why do we use CSS?

In early HTML, HTML allowed markup that was presentational, and CSS did not exist.

Moving from HTML4 to HTML5, we removed a lot of the appearance tags in order to incentivise making HTML and CSS seperate languages.

A lot of the appearance tags still work on browsers (as a lot of websites are still on old HTML versions), so you should use a validation website to make sure that you are not using any deprecated tags

Some tags have been changed going from HTML4 to HTML5

b (bold -> bring to attention), i (italic -> interesting text), big (larger font -> removed), small(smaller font -> small print (legal stuff)).

But why are we using 2 different languages and seperating them?

"You build a house, and then paint it. You dont paint a house while its being built" - DGB

"You want builders to build a house, and decorators (creative people) to paint a house. These two activities are completely different" - DGB

Check out CSS Zen Garden for more information (each page is the same HTML, just different CSS)

How to add CSS to web pages

  • Inline Stylesheets
  • Embedded Stylesheets
  • External Stylesheets

Inline Styles

In HTML, style is a global attribute. You can put CSS declarations onto elements

inline_style.html
<h1 style="color: red; background-color: green">Title here</h1>

Disadvantages: Harder to maintain and modify, you have to change multiple styles and its easy to miss something. It also bloats the whole page

Embedded Stylesheets

You can embed CSS into your website using a <style> tag, usually in the head

embedded_style.html
<head>
    <meta charset="utf-8" />
    <title>Welcome!</title>
    <style>
        p {
            color: red;
        }

        h2 {
            color: white;
            background-color: black;
        }
    </style>
</head>

They are not ideal, especially when several web pages should look and feel about the same (inconsistent design).

External Stylesheets

External stylesheets are when your CSS is in a seperate file, and is linked into a HTML page through a link tag, similar to favicon linking

embedded_style.html
<head>
    <meta charset="utf-8" />
    <title>Welcome!</title>
    <link rel="stylesheet" href="styles.css" />
</head>

All styles on all pages can be changed in one place

CSS Terminology

A CSS file contains:

  • Zero, one or more rules
  • Zero, one or more @rules
  • comments

A rule comprises

  • one or more selectors and
  • a block of zero, one or more declarations in curly braces

A declatation comprises of:

  • a property and
  • its value, separated by a colon

and is usually terminated by a semi-colon

CSS Inheritance

Similar to the heirarchal structure in HTML (or filesystems, but focus on HTML), CSS operates on an inheritance structure.

If a paragraph tag is set to red in CSS, then any tags within the paragraph also have the same CSS by inheritance.

Inheritance

If a paragraph tag is set to red in CSS, then any tags within the paragraph also have the same CSS by inheritance.

Say, for example, the italics dont like red (theyre fussy blokes), italics can BLOCK INHERITANCE.

In the CSS, if you make a rule in CSS for italics to be blue (below the red paragraph rule), it will block the red inheritance on the italic tag.

NOT EVERYTHING IS INHERITED

An improved definition for inheritance:

"For a given property, when no value for that property has been specifed, an element's value for that property comes from its parent."

Example: If a p tag has a black border (like a box), the child elements will not inherit its parents CSS

The DGB definition:

At a rough approximation, the ones that are inherited are the ones concerned with the text: text colour, font, text spacing (discussed more for lecture 18)

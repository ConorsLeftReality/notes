Logical Structure

We often want to group consecutive elements that are logically related, e.g. a heading and the paragraphs after it form a section.

Why?

  • These chunks can be targets for CSS & JavaScript
  • They give info to screen-readers & search engine crawlers

The div Element

Older HTML grouped everything with <div>, but div is very generic, so developers stuck loads of id attributes on them to show what each one was for.

HTML5 Elements for Structure

  • header - a group of introductory elements
  • nav - a group of navigation links (a navigation menu)
  • main - the main content of the page (only one per page, and never nested inside the other elements in this list)
  • aside - content only loosely related to the page or what's around it (e.g. an advertising sidebar)
  • footer - info about the page/section/article (author, copyright, etc.)
  • div - still exists, but only as a last resort when nothing else fits

Sections and Articles

A section is a thematic grouping, usually part of a larger whole.

An article is also a thematic grouping, but one that is self-contained.

Sections and articles can be nested inside other sections and articles.

Rule of thumb

If you can imagine copying the content and reusing it on another page or site, use article. E.g. press releases, news stories, blog posts, adverts.

Advice

  • A section/article shouldn't usually contain just one paragraph
  • The validator will warn you if a section/article has no heading
  • Use headings of the right rank (h1-h6) for how deep the nesting is
  • Try to pick the right one of section vs article, but there are no real consequences, so don't over-think it

Words and Phrases

Sometimes we want to mark up a word or phrase so it stands out (same reasons as above: CSS/JS targets, screen-readers and crawlers).

The span Element

<span> is the phrase-level version of div: very generic, so only use it as a last resort.

Elements for Words or Phrases

  • em (emphasis) - to emphasise a word or phrase, especially for contrast. E.g. That's not a bee! It's a wasp!
  • strong (strong importance) - for something important, serious or urgent. E.g. Save your work to disk frequently.
  • i (interesting text) - to set apart titles, names, technical terms and foreign-language phrases
  • b (bring to attention) - to pick out keywords or key phrases
NOTE

b does not mean 'bold' and i does not mean 'italic'. The browser's default CSS just happens to show b and strong in bold, and i and em in italic.

Don't over-do it: only mark up words that actually need to be distinguished from the text around them. Try to pick the right one of em/strong/i/b, but again, don't over-think it.

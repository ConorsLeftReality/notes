Exam Format

1.5 hours, answer ALL 6 questions (10 marks each in 2025). No calculators. A formula sheet (derivatives, integrals, trig) is given at the back.

The same 6 questions every year

2023, 2024 and 2025 all had the exact same 6 types of question in the same order. Practise these 6 and you've practised the exam.

  1. Piecewise function: values, increasing/decreasing, sketch it, sketch a transformed version
  2. Solve a log equation
  3. Equation of a tangent line
  4. Related rates
  5. Critical points, increasing/decreasing, sketch
  6. Which function satisfies this differential equation?

Q1 to Q3

Q1 - Piecewise functions

To get f(a), find which piece's range a falls into (watch < vs ≤). Decreasing on an interval = derivative of that piece is negative there.

g(x) = f(−x) + c: reflect the graph in the y-axis, then shift it up by c.

E.G. (2024) f = x² for x < −1, 0 for −1 ≤ x < 1, ln x for x ≥ 1. So f(−1) = 0, f(1) = ln 1 = 0, and on (−∞, −1), f' = 2x < 0, so it's decreasing.

Q2 - Log equations

Get all the logs on one side, combine with log a + log b = log(ab) or log a − log b = log(a/b), then log2(stuff) = 3 means stuff = 23 = 8.

Always check the answers in the original equation - you can't take the log of a negative number, so usually one answer gets thrown out.

E.G. (2024) log2(x+1) = 3 − log2(x−1) → (x+1)(x−1) = 8 → x² = 9 → x = 3 (x = −3 is out)

E.G. (2025) log2(x²−6x) = 3 + log2(1−x) → x²−6x = 8(1−x) → x²+2x−8 = 0 → x = 2 or −4. Need 1−x > 0, so x = −4

Q3 - Tangent lines

Point: y0 = f(a). Slope: m = f'(a) (it's always a chain rule one). Line: y − y0 = m(x − a).

E.G. (2024) y = esin x at x = π: y = e0 = 1, y' = cos x · esin x = −1, so y = −x + π + 1

Q4 to Q6

Q4 - Related rates

  1. Draw it and name the changing things (x, y, θ, shadow s...)
  2. Write an equation linking them (Pythagoras, similar triangles, tan θ)
  3. Differentiate both sides with respect to t
  4. Only then plug in the numbers

E.G. (2024) circle x² + y² = 100² → 2x x' + 2y y' = 0 → y' = −(60)(10)/80 = −7.5 m/s

E.G. (2025) streetlight 4.5m, car 1.8m, shadow s, distance x. Similar triangles: 4.5/(x+s) = 1.8/s → s = 2x/3 → s' = (2/3)(−9) = −6 m/s (shrinking)

Q5 - Critical points and sketching

Set f'(x) = 0 (quotient rule for fractions), then check the sign of f' between the critical points: + = increasing, − = decreasing. Also say what happens as x → ±∞.

E.G. (2024) f = x/(x²+1), f' = (1−x²)/(x²+1)² = 0 at x = ±1. Decreasing, increasing, decreasing. Min (−1, −½), max (1, ½), and f → 0 at both ends.

Q6 - Checking a differential equation

For each option, work out the left side (df/dx) and the right side separately, and see if they match. More than one can work!

E.G. (2025) df/dx = −f + e−x. For f = xe−x: left = e−x − xe−x, right = −xe−x + e−x. Same, so (c) works. The others don't.

E.G. (2024) df/dx = −f/x + 3x: both x² and x² + 1/x work.

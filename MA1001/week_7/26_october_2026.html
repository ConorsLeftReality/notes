Question 1: Piecewise Functions, Domains & Graph Transformations

f(x) =

−2x if x < −1
x2 + 1 if −1 ≤ x < 2
ln x if x ≥ 2
  1. Evaluation: Calculate f(−1), f(0), and f(2).
  2. Domain & Monotonicity: State the natural domain of f(x) in interval notation, and determine whether f is increasing or decreasing on (−∞, −1).
  3. Graphing: Sketch the graph of y = f(x) for −2 < x < 4.
  4. Transformations: Sketch the transformed graph g(x) = f(−x) + 3 and state the transformation operations applied.

Question 1

This question is on "Piecewise Functions, Domains & Graph Transformations

  • A piecewise function is a function that uses different formulas or rules for different intervals of its domain.
  • The domain of a function is the complete set of all possible input values (\(x\)-values) that can be plugged into the function to produce a valid, defined output.
  • Graph transformations are operations that change the position, shape, or orientation of a function's graph on the coordinate plane without altering its core fundamental behavior
    • E.G. f(x) + 3 is a graph transformation that vertically translates a graph up 3 units

Translation

  • (1) The question is asking to say that x = -1, 0 and 2 for each applicable form of the piecewise functions. The Important Part of this question is to notice that you have to figure out which piecewise function you have to use for each value of x.
    • f(-1), or x = -1 is only applicable to x2 + 1, and no other functions
    • f(0), or x = 0 is only applicable to x2 + 1 because -1 ⩽ x < 2
    • f(2), or x = 2 is only applicable to x ≥ 2
  • (2) The question is asking you to find the range(s) of numbers that give a valid output to the function stated, and state whether f is increasing or decreasing on (-∞,-1).
    • (a) These valid intervals are written as ranges, then answered using parentheses and square brackets ( ()/[] ).
      • -1 ≤ x < 5 is written as [-1,5)
      • 9 > x ≥ 1 is written as [1,9)
    • (b) To find whether f is increasing or decreasing on a specific interval range, we need to look at the piecewise function for this. There are two methods to figuring out the slope here.
      1. Look at the function: we can see that f(x) = -2x is if x < -1, which it is in the interval (-∞-1). From this we can tell that the functions slope is a negative straight line as the overall function is negative (-2x)
      2. Derivation: we can derive the function and figure out what the slope is from there. From this, we can see that f'(x) = -2, giving us a negative slope.
  • (3) We are asked to sketch a graph of y = f(x) for -2 < x < 4. This is simple, and just involves knowing how each function is shaped.
    • f(x) = -2x is just a straigh line downwards with slope of -2
    • f(x) = x2 + 1 is just a centered quadratic x2 with a vertical translation of +1
    • f(x) = lnx is just a logarithmic graph, opposite of exponential, slope slows down as x progresses.
  • (4) The question NOW asks to transform the graph so that the graph g(x) = f(-x) + 3. We are also asked to state transformations applied. This involves 2 steps
    1. Reflect in the y-axis (x is now -x): this flips the graph left to right.
    2. Translate up 3 units (the +3 outside the brackets): every y-value goes up by 3.
    Other transformations that could come up are listed below
    Transformation Form What it does Short explanation
    Vertical shift upf(x) + cUp c unitsAdds c to every y-value: (a, b) → (a, b + c)
    Vertical shift downf(x) − cDown c unitsSubtracts c from every y-value
    Horizontal shift rightf(x − c)Right c unitsInput must be c larger for the same output: (a, b) → (a + c, b)
    Horizontal shift leftf(x + c)Left c unitsInput can be c smaller for the same output
    Reflection in the y-axisf(−x)Flips left to rightChanges the sign of every x-value: (a, b) → (−a, b)
    Reflection in the x-axis−f(x)Flips upside downChanges the sign of every y-value: (a, b) → (a, −b)
    Vertical stretch (a > 1)a·f(x)Taller, away from the x-axisMultiplies every y-value by a
    Vertical compression (0 < a < 1)a·f(x)Flatter, toward the x-axisMultiplies every y-value by a fraction
    Horizontal stretch (c > 1)f(x/c)Wider, away from the y-axisMultiplies every x-value by c: (a, b) → (ca, b)
    Horizontal compression (b > 1)f(bx)Narrower, toward the y-axisMultiplies every x-value by 1/b

Answers

  • (1) f(-1) = (-1)2 + 1 = 2, f(0) = 0 + 1 = 1, f(2) = ln 2 ≈ 0.693
  • (2) The three pieces cover every real number, so the domain is (-∞, ∞). On (-∞, -1), f(x) = -2x has slope -2, so f is decreasing.
  • (4) g(x) = f(-x) + 3: reflect in the y-axis, then shift up 3.

Question 2

This question is on "Exponential & Logarithmic Equations & Domains"

  • The natural domain of ln(something) is wherever that something is strictly positive (ln of 0 or a negative doesn't exist).
  • To solve log equations, use the log laws to combine everything into one log, then undo it with the base.
  • To solve when x is in a power, take ln of both sides so the powers come down.

Translation

  • (1) Domain of g(x) = ln(x2 - x - 2): we need x2 - x - 2 > 0.
    • Factor: (x - 2)(x + 1) > 0
    • A product is positive when both brackets are positive (x > 2) or both are negative (x < -1)
    • Answer: (-∞, -1) ∪ (2, ∞)
  • (2) Solve log2(x - 5) = 4 - log2(x + 1)
    • Move the log over: log2(x - 5) + log2(x + 1) = 4
    • Combine (log a + log b = log ab): log2((x - 5)(x + 1)) = 4
    • Undo the log: (x - 5)(x + 1) = 24 = 16, so x2 - 4x - 21 = 0, so (x - 7)(x + 3) = 0
    • x = -3 would mean log2(-8), which doesn't exist, so throw it away
    • Answer: x = 7
  • (3) Solve 2x+1 = 3x-1
    • Take ln of both sides: (x + 1) ln 2 = (x - 1) ln 3
    • Get the x terms together: x ln 3 - x ln 2 = ln 2 + ln 3
    • x (ln 3 - ln 2) = ln 6, so x = ln 6 / ln(3/2)
    • Answer: x = ln 6 / ln 1.5 ≈ 4.419 (only one real solution)

Question 3

This question is on "Limits, Radical Conjugates & Asymptotes"

  • A limit is the value a function heads towards as x gets close to a number. Always try substituting first. If you get 0/0, simplify and try again.
  • The conjugate of √A - √B is √A + √B. Multiplying them gives A - B, which gets rid of the roots.
  • Vertical asymptotes are where the bottom is 0 (and the top isn't). Horizontal asymptotes are the limits as x → ±∞.

Translation

  • (1) limt→4 (t2 - 2t - 8) / (√(t + 5) - √(4t - 7)). Substituting t = 4 gives 0/0.
    • Top factors: t2 - 2t - 8 = (t - 4)(t + 2)
    • Multiply top and bottom by the conjugate √(t + 5) + √(4t - 7)
    • Bottom becomes (t + 5) - (4t - 7) = 12 - 3t = -3(t - 4)
    • Cancel (t - 4): we're left with -(t + 2)(√(t + 5) + √(4t - 7)) / 3
    • Now substitute t = 4: -(6)(3 + 3) / 3
    • Answer: -12
  • (2) limθ→0 sin(3θ) / (2θ). Use the standard limit sin(u)/u → 1.
    • Rewrite: (3/2) · sin(3θ) / (3θ)
    • As θ → 0, 3θ → 0 too, so sin(3θ)/(3θ) → 1
    • Answer: 3/2
  • (3) Asymptotes
    • k(x) = √(4x2 + 3) / x: the bottom is 0 at x = 0 (top is √3, not 0), so vertical asymptote x = 0. For large x, √(4x2 + 3) ≈ 2|x|, so k(x) → 2 as x → ∞ and → -2 as x → -∞. Horizontal asymptotes y = 2 and y = -2.
    • g(x) = x2 / (x + 3): vertical asymptote x = -3. The top has a higher degree than the bottom, so there's no horizontal asymptote (it actually follows the slant line y = x - 3, since x2/(x + 3) = x - 3 + 9/(x + 3)).

Question 4

This question is on "Continuity Parameters & Intermediate Value Theorem (IVT)"

  • A function is continuous at a point if you can draw through it without lifting your pen: the value there equals the limit from both sides.
  • For a piecewise function, the pieces must meet at every join.
  • The IVT: if f is continuous on [a, b], it hits every value between f(a) and f(b). So if f(a) and f(b) have opposite signs, f = 0 somewhere in between.

Translation

  • (1) Find a and b so f is continuous
    • Join at x = 1: left piece 2(1) = 2 must equal a(1)2 + b, so a + b = 2
    • Join at x = 2: a(2)2 + b must equal the right piece 4(2) = 8, so 4a + b = 8
    • Subtract the first from the second: 3a = 6
    • Answer: a = 2, b = 0
  • (2) Show (cos x)x3 + 5 sin4x - 4 = 0 has a solution in [0, 2π]
    • Let f(x) = (cos x)x3 + 5 sin4x - 4. It's built from cos, sin and powers by adding and multiplying, so it's continuous on [0, 2π]
    • f(0) = (1)(0) + 0 - 4 = -4 < 0
    • f(2π) = (1)(2π)3 + 0 - 4 = 8π3 - 4 ≈ 244 > 0
    • Answer: f changes sign on [0, 2π], so by the IVT there's a c in (0, 2π) with f(c) = 0

Question 5

This question is on "Advanced Tangent Lines & Normal Lines"

  • The tangent at x = a has slope f'(a): y - f(a) = f'(a)(x - a).
  • The normal is perpendicular to the tangent, so its slope is -1/f'(a).
  • Parallel lines have the same slope.

Translation

  • (1) Tangents to y = x2 through (1, -3). The point (1, -3) isn't on the curve, so we don't know where the tangents touch yet.
    • Call the touching point (a, a2). The slope there is 2a, so the tangent is y - a2 = 2a(x - a)
    • It has to pass through (1, -3): -3 - a2 = 2a(1 - a) = 2a - 2a2
    • Tidy up: a2 - 2a - 3 = 0, so (a - 3)(a + 1) = 0, a = 3 or a = -1
    • Answer: y = 6x - 9 and y = -2x - 1 (both pass through (1, -3) ✓)
  • (2) Tangents to 3y = x3 - 3x2 + 6x + 4 parallel to 2x - y + 3 = 0
    • The line is y = 2x + 3, so we want slope 2
    • y = (x3 - 3x2 + 6x + 4)/3, so y' = x2 - 2x + 2
    • x2 - 2x + 2 = 2, so x(x - 2) = 0, x = 0 or x = 2
    • Points: (0, 4/3) and (2, 4)
    • Answer: y = 2x + 4/3 and y = 2x
  • (3) Normal to y = 2 / (x2 - 2x - 4)2 at (3, 2)
    • Write it as y = 2u-2 with u = x2 - 2x - 4 (chain rule)
    • y' = -4u-3 · (2x - 2)
    • At x = 3: u = 9 - 6 - 4 = -1, so y' = -4(-1)(4) = 16
    • Normal slope = -1/16, so y - 2 = -(1/16)(x - 3)
    • Answer: y = -x/16 + 35/16 (or x + 16y - 35 = 0)

Question 6

This question is on "Differentiation Rules, Abstract Derivatives & DE Verification"

  • Quotient rule: (u/v)' = (u'v - uv') / v2. Product rule: (uv)' = u'v + uv'. Chain rule: derivative of the outside (inside kept the same) times derivative of the inside.
  • A differential equation links a function and its derivatives. To "verify" one, differentiate, substitute in, and show both sides match.

Translation

  • (1a) y = (1 - cos 3x) / (1 + cos 3x)
    • u = 1 - cos 3x, u' = 3 sin 3x; v = 1 + cos 3x, v' = -3 sin 3x
    • y' = [3 sin 3x (1 + cos 3x) + 3 sin 3x (1 - cos 3x)] / (1 + cos 3x)2
    • The cos 3x terms cancel on top, leaving 3 sin 3x · 2
    • Answer: y' = 6 sin 3x / (1 + cos 3x)2
  • (1b) f(t) = ln[(t + 3) sin t]
    • Split it first with log laws: f(t) = ln(t + 3) + ln(sin t)
    • Answer: f'(t) = 1/(t + 3) + cos t / sin t = 1/(t + 3) + cot t
  • (2) F(x) = f(cos x) and G(x) = cos(f(x)), using the chain rule
    • F'(x) = f'(cos x) · (-sin x) = -sin x · f'(cos x)
    • G'(x) = -sin(f(x)) · f'(x)
  • (3) Show y = a sin kx + b cos kx satisfies d2y/dx2 + k2y = 0
    • dy/dx = ak cos kx - bk sin kx
    • d2y/dx2 = -ak2 sin kx - bk2 cos kx = -k2(a sin kx + b cos kx) = -k2y
    • So d2y/dx2 + k2y = -k2y + k2y = 0 ✓ for any a and b

Question 7

This question is on "Trigonometric Equations & Inverse Functions"

  • Trig equations often turn into quadratics once you use an identity like 1 + tan2x = sec2x.
  • tan repeats every π, so "all real solutions" means adding nπ (n any integer).
  • A function only has an inverse if it's one-to-one. If it isn't, restrict its domain.

Translation

  • (1) Solve sec2x + 5 tan x = -2
    • Replace sec2x with 1 + tan2x: tan2x + 5 tan x + 3 = 0
    • Quadratic formula in tan x: tan x = (-5 ± √13) / 2, i.e. tan x ≈ -0.697 or tan x ≈ -4.303
    • Answer: x = arctan((-5 + √13)/2) + nπ ≈ -0.609 + nπ, or x = arctan((-5 - √13)/2) + nπ ≈ -1.342 + nπ (n any integer)
  • (2) f(x) = √(4 - x2): restrict the domain so it's one-to-one, then find f-1
    • On [-2, 2] the graph is a semicircle, which fails the horizontal line test. Restrict to [0, 2], where it only goes down
    • Swap and solve: y = √(4 - x2), so y2 = 4 - x2, so x = √(4 - y2) (positive root, since x ≥ 0)
    • Answer: on [0, 2], f-1(x) = √(4 - x2) (it's its own inverse!). If you pick [-2, 0] instead, f-1(x) = -√(4 - x2)
  • (3) Verify f(x) = 1/(x + 1) and g(x) = (1 - x)/x are inverses
    • (f ∘ g)(x) = 1 / ((1 - x)/x + 1) = 1 / ((1 - x + x)/x) = 1 / (1/x) = x
    • (g ∘ f)(x) = (1 - 1/(x + 1)) / (1/(x + 1)) = (x/(x + 1)) · (x + 1) = x
    • Both give x (for x ≠ 0, -1), so they are inverses ✓

Question 8

This question is on "Exponential Growth/Decay Models & Power Fitting"

  • Exponential growth: S(t) = cekt, where c is the starting amount and k is the growth rate.
  • Doubling time = ln 2 / k. Half-life works the same way for decay.
  • For a power function y = a·xn through two points, divide one equation by the other so a cancels.

Translation

  • (1) 1,000 bacteria grow to 5,000 in 7 hours
    • c = 1000, and 1000e7k = 5000, so e7k = 5, so k = ln 5 / 7 ≈ 0.230 per hour
    • Doubling time: 2c = cekT, so T = ln 2 / k = 7 ln 2 / ln 5 ≈ 3.01 hours
    • Reaching 1,000,000: 1000ekt = 1,000,000, so ekt = 1000, so t = ln 1000 / k = 7 ln 1000 / ln 5
    • Answer: about 30.0 hours
  • (2) A fossil has lost 58% of its carbon-14 (half-life 5,730 years)
    • Lost 58% means 42% is left: 0.42 = (1/2)t/5730
    • Take ln: ln 0.42 = (t/5730) ln 0.5, so t = 5730 × ln 0.42 / ln 0.5
    • Answer: about 7,170 years ago
  • (3) Find a and n so y = a·xn passes through (2, 12) and (5, 75)
    • 12 = a·2n and 75 = a·5n
    • Divide: 75/12 = (5/2)n, so 6.25 = 2.5n, so n = 2
    • Back in: 12 = a·4, so a = 3
    • Answer: a = 3, n = 2, i.e. y = 3x2 (check: 3·25 = 75 ✓)

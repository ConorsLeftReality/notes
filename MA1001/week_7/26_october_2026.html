Question 1: Piecewise Functions, Domains & Graph Transformations

Consider the piecewise function:

f(x) =

−2x if x < −1
x2 + 1 if −1 ≤ x < 2
ln x if x ≥ 2
  1. Evaluation: Calculate f(−1), f(0), and f(2).
  2. Domain & Monotonicity: State the natural domain of f(x) in interval notation, and determine whether f is increasing or decreasing on (−∞, −1).
  3. Graphing: Sketch the graph of y = f(x) for −2 < x < 4.
  4. Transformations: Sketch the transformed graph g(x) = f(−x) + 3 and state the transformation operations applied.

Question 2: Exponential & Logarithmic Equations & Domains

  1. Logarithmic Domain: Find the natural domain of g(x) = ln(x2 − x − 2) and give your answer in interval notation.
  2. Logarithmic Equation: Solve for x: log2(x − 5) = 4 − log2(x + 1).
  3. Exponential Base Change: Find all real solutions to 2x+1 = 3x−1.

Question 3: Limits, Radical Conjugates & Asymptotes

  1. Indeterminate Conjugate Limit: Evaluate limt→4 (t2 − 2t − 8) / (√(t + 5) − √(4t − 7)).

  3. Asymptotes: Find all horizontal and vertical asymptotes for k(x) = √(4x2 + 3) / x and g(x) = x2 / (x + 3).

Question 1

This question is on "Piecewise Functions, Domains & Graph Transformations

  • A piecewise function is a function that uses different formulas or rules for different intervals of its domain.
  • The domain of a function is the complete set of all possible input values (\(x\)-values) that can be plugged into the function to produce a valid, defined output.
  • Graph transformations are operations that change the position, shape, or orientation of a function's graph on the coordinate plane without altering its core fundamental behavior
    • E.G. f(x) + 3 is a graph transformation that vertically translates a graph up 3 units

Translation

  • (1) The question is asking to say that x = -1, 0 and 2 for each applicable form of the piecewise functions. The Important Part of this question is to notice that you have to figure out which piecewise function you have to use for each value of x.
    • f(-1), or x = -1 is only applicable to x2 + 1, and no other functions
    • f(0), or x = 0 is only applicable to x2 + 1 because -1 ⩽ x < 2
    • f(2), or x = 2 is only applicable to x ≥ 2
  • (2) The question is asking you to find the range(s) of numbers that give a valid output to the function stated, and state whether f is increasing or decreasing on (-∞,-1).
    • (a) These valid intervals are written as ranges, then answered using parentheses and square brackets ( ()/[] ).
      • -1 ≤ x < 5 is written as [-1,5)
      • 9 > x ≥ 1 is written as [1,9)
    • (b) To find whether f is increasing or decreasing on a specific interval range, we need to look at the piecewise function for this. There are two methods to figuring out the slope here.
      1. Look at the function: we can see that f(x) = -2x is if x < -1, which it is in the interval (-∞-1). From this we can tell that the functions slope is a negative straight line as the overall function is negative (-2x)
      2. Derivation: we can derive the function and figure out what the slope is from there. From this, we can see that f'(x) = -2, giving us a negative slope.
  • (3) We are asked to sketch a graph of y = f(x) for -2 < x < 4. This is simple, and just involves knowing how each function is shaped.
    • f(x) = -2x is just a straigh line downwards with slope of -2
    • f(x) = x2 + 1 is just a centered quadratic x2 with a vertical translation of +1
    • f(x) = lnx is just a logarithmic graph, opposite of exponential, slope slows down as x progresses.
  • (4) The question NOW asks to transform the graph so that the graph g(x) = f(-x) + 3. We are also asked to state transformations applied. This involves 2 steps
    1. Reflect in the y-axis (x is now -x): this flips the graph left to right.
    2. Translate up 3 units (the +3 outside the brackets): every y-value goes up by 3.
    Other transformations that could come up are listed below
    Transformation Form What it does Short explanation
    Vertical shift upf(x) + cUp c unitsAdds c to every y-value: (a, b) → (a, b + c)
    Vertical shift downf(x) − cDown c unitsSubtracts c from every y-value
    Horizontal shift rightf(x − c)Right c unitsInput must be c larger for the same output: (a, b) → (a + c, b)

    Vertical compression (0 < a < 1)a·f(x)Flatter, toward the x-axisMultiplies every y-value by a fraction

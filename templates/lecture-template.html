What is a database?

A database is an organised collection of data that can be stored, queried and updated efficiently. Most apps use a relational database such as PostgreSQL or MySQL. Important words can be highlighted.

Definition: DBMS

A Database Management System is the software that lets you create, read, update and delete data.

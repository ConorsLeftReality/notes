Contribution

So, you are probably here for one of three reasons

  • Some of my notes are incomplete/inaccurate and you want to add/improve them
  • You are super enthusiastic about open-source, or want to learn it
  • You're madly in love with me and really want to stand out (highly unlikely, so lets make it one of two reasons)

If you are here for any of these three two reasons, then look no further!

As of now (October something to Present), this website is ran on GitHub Pages. To learn more, visit this page for more information

The site hosted on GitHub is using files from, you guessed it, a GitHub Repository (Info Here).
